# 📖 About the Project

Financial sentiment plays a crucial role in investment decisions and market forecasting.

This project combines multiple financial sentiment datasets and evaluates both traditional machine learning approaches and transformer-based language models.

### Dataset Sources

- Financial PhraseBank
- Twitter Financial News Sentiment
- FiQA Sentiment Classification

### Objectives

- Financial text classification
- NLP preprocessing
- Feature engineering
- Machine Learning model comparison
- FinBERT fine-tuning
- Explainable AI analysis
